# 판루딕 한 단계 개선 · 2026-11-10

목적: 기존 12종과 미니 체스를 작은 조작·진행 안내 개선으로 다듬는다. 규칙, 난수, 점수, 기록 키와 복습 구분은 유지한다. 덱빌더와 숨김 게임은 보류한다.

1. 공개 정보로만 계산하는 보조 함수와 검증을 만든다.
2. 숫자 메모, 선택 정리, 배치·진행 피드백을 통합하고 기존 회귀·반응형·저장 복구를 검사한다.
3. 승인된 기존 Render 서비스로 배포하고 실제 서비스의 자산·플레이·저장·복구를 확인한다.

구현 중. 새 메모는 세션의 선택적 view 필드에 저장한다. 기존 저장 자료에는 기본 빈 메모를 적용한다. 미니 체스는 화면의 이동 가능 칸 안내만 보강한다. 온라인 서버는 변경하지 않는다.

## 구현 및 로컬 검수

- 숫자야구·코드 브레이커: 직접 표시하는 후보/제외 숫자 메모와 진행 복구.
- 불빛: 누르기 전 실제 십자 영향 범위(풀이 힌트가 아닌 조작 범위).
- 트리플: 선택 수·선택 비우기. 기억의 짝: 공개된 완성 과일 모음.
- 주사위: 마지막 배치 표시와 복구. 숫자 연쇄: 카드별 가능한 연결 방향.
- 라인: 중앙 보너스를 포함한 현재 배치 합계, 남은 수 안내.
- 벽돌: 3단계·목숨 표시. 사천성: 직전 연결의 꺾임 수·실제 증가 점수.
- 블록 팝: 올클리어 보너스를 포함한 정확한 제거 점수, 제거 후 남은 수·연결 그룹 수.
- 버블: 지난 발사의 연결 제거·낙하·실제 증가 점수, 조준 변경/복구 시 유지.
- 미니 체스 로컬/온라인: 선택한 말의 이동·포획 가능 칸 수 표시. 서버 변경 없음.

전체 엔진 검사, 새 UI 60개 화면 폭 조합, 기존 아케이드 완주/복구/저장 실패 재시도, 정규·복습 기록 분리, 키보드 조작, 60개 아기자기 디자인 화면, 팝업 완주·중복 기록 방지 검사를 통과했다. 테스트 하네스는 새 패널로 이동한 모바일 게임판을 스크롤한 뒤 실제 좌표를 구하도록 조정했다. 새 검사 중 자동 팝업 복구와 pair API 객체 형식을 잘못 가정한 부분을 수정했다. 제품 오류로 은폐하지 않았다.

다음: 최종 산출물 빌드, 기존 서비스 자동 배포, 배포 커밋/정적 자산 대조 및 실제 서비스 플레이·저장·복구 재검사.
