# 진행·최고 기록 보호 · 2026-11-21

분기: codex/panludiq-design-schema. 기존 체크아웃을 유지한다.

1. 별도 최고 기록 저장소와 오래된 진행 저장 거부를 구현하고 단위 검사한다.
2. 팝업 탭 소유권·이어하기, 기록 UI를 연결하고 다중 탭/닫기 순서/정규·복습/저장 실패 회귀 검사를 한다.
3. 기존 Render 정적 서비스 배포 후 같은 검사를 실제 서비스에서 확인한다.

기존 기록 키와 100개 최근 목록은 유지한다. 최고 기록은 추가 키에 보존하고 정규/복습·게임·규칙·난이도를 구분한다. 이미 과거에 목록 밖으로 지워진 기록은 복원할 수 없다. 상태·기록 형식 버전은 바꾸지 않는다. 온라인 서버는 변경하지 않는다. 로그와 재개 정보는 이 문서에 남긴다.
