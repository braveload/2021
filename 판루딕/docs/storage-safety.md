# 진행·최고 기록 보호 · 2026-11-21

분기: codex/panludiq-design-schema. 기존 체크아웃을 유지한다.

1. 별도 최고 기록 저장소와 오래된 진행 저장 거부를 구현하고 단위 검사한다.
2. 팝업 탭 소유권·이어하기, 기록 UI를 연결하고 다중 탭/닫기 순서/정규·복습/저장 실패 회귀 검사를 한다.
3. 기존 Render 정적 서비스 배포 후 같은 검사를 실제 서비스에서 확인한다.

기존 기록 키와 100개 최근 목록은 유지한다. 최고 기록은 추가 키에 보존하고 정규/복습·게임·규칙·난이도를 구분한다. 이미 과거에 목록 밖으로 지워진 기록은 복원할 수 없다. 상태·기록 형식 버전은 바꾸지 않는다. 온라인 서버는 변경하지 않는다. 로그와 재개 정보는 이 문서에 남긴다.

## 1단계 완료

별도 .best.v1 키에 최고점·최소 이동·최소 시도 기록을 게임/규칙/모드/난이도/선후공/결과별 보존한다. 이전 기록은 읽어 이관하며 최근 목록 원본을 재작성하지 않는다. 정규와 복습의 키는 별도다. 저장소별 마지막으로 읽은 세션 원본과 쓰기 직전 원본이 다르면 오래된 저장을 거절한다. ee94eee.

## 2단계 구현·검사

팝업은 게임별 작성 탭 토큰으로 저장·타이머·완료를 보호한다. 다른 탭은 읽기 전용으로 열고 '이 탭에서 이어하기'로 최신 저장을 가져온다. 떠나는 오래된 탭은 소유권·진행·자동복구 표시를 지우지 못한다. 소유 탭이 닫히면 해제하고 비정상 종료 후에도 명시적으로 이어받을 수 있다. 최근 목록과 역대 최고를 분리해 표시하며 기록 수는 최근 100개 기준임을 안내한다. 명시적 기존 기록 삭제는 관련 최고 요약도 함께 삭제한다. 숨김 나인 기록은 유지한다.

로컬 새 다중 탭 검사: 두 가지 닫기 순서, 소유권 왕복, 완료 세션 재생성 방지, 새 도전, 숫자야구 입력·트리플 선택 복구, 솔로/아케이드 최신 진행 반영, 최고점 100개 초과·새로고침·홈/개별 화면 일치, 정규/복습 요약 분리 통과. 1280/390/320 폭에서 확인. 기존 저장복구, 복습, 팝업 완주, 아케이드 완주/실패/저장 공간 실패 재시도, 키보드 검사 통과.

테스트 하네스 최초 오류는 about:blank에서 게스트 프로필을 쓰던 초기화 코드였다. HTTP(S) 문서에만 검수 프로필을 쓰도록 수정했다. 제품 오류를 무시하지 않았다. 단계 후 재개: 최신 빌드·단위 검사, 새 다중 탭 검사 최종 재실행, 배포 및 실제 서비스 재검사. 이미 지워진 과거 기록은 복원하지 못하며 현재 남은 기록과 이후 기록을 보호한다.

최고 요약은 구분별 작은 추가 키에도 보존한다. 서로 다른 게임의 동시 저장으로 공통 요약의 마지막 쓰기가 겹쳐도 이 키들을 읽어 복구한다. 12쌍의 서로 다른 게임 동시 쓰기 검사를 추가해 통과했다. 최근 기록과 별개로 최고 요약의 손상·저장 공간 실패를 검수하며, 원본은 백업한다. 기존 숨김 기록 삭제 예외도 유지했다.

배포 중 저장 관련 새/이전 스크립트 혼용 방지를 위해 해당 8개 파일은 빌드 때 내용 해시 이름으로 복사하고 배포 HTML 참조만 바꾼다. 원본 파일과 기존 URL도 남긴다. 해시는 BOM/줄바꿈 정규화 후 계산해 Windows/Linux가 같다. storage-assets.json은 배포 자산 검증에 사용한다.
