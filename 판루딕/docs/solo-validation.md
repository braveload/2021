# 공통 싱글게임 3종 개발·검증 결과

2026년 11월 3일 · 로컬 개발 완료 · 배포하지 않음

## 목적

코드 브레이커, 리버스 타일, 전략 주사위를 먼저 구현하고 공통 엔진·진행 저장·완료 기록이 서로 다른 게임에서도 작동하는지 확인한다. 기존 숫자야구·불빛 뒤집기는 규칙이 다른 기존 게임으로 보존한다. 덱빌더와 새 숫자 심리전은 노출하거나 개발을 재개하지 않는다.

## 구현

|게임|규칙|기록|
|---|---|---|
|코드 브레이커|0~7 중 서로 다른 4자리, 8회 도전|성공·실패, 점수, 시도 수|
|리버스 타일|4×4, 해당 칸·상하좌우 반전, 모두 밝게, 최대25회|성공·실패, 조작 수, 초기 별 기준|
|전략 주사위|두 주사위 중 하나를3×3 빈칸에 배치,9턴|완료, 최종 점수와 줄별 보너스|

모두 공통 `create → legalActions/apply → result → record` 경로를 사용한다. 규칙과 UI는 분리했다. 동일 브라우저에서 게임별 진행을 복구하며 문제·시도·주사위·선택·난수 상태를 유지한다. 완료한 경기만 기록하고 중단한 경기는 완료 기록에 넣지 않는다. 신규3종의 최근100경기를 보관하며 게임별 성공 기록 안에서 최고/최소를 비교한다.

## 검증

- 코드: 잘못된 범위·중복·재제출이 기회를 소비하지 않음, 힌트 합계,8번째 정답 성공/오답 실패,1000~300점과 실패0점.
- 리버스: 독립 계산으로65,536개 조작 조합의 도달 상태 확인,500개 생성 문제 해답 적용,25번째 성공 우선,경계 인접 판정.
- 주사위: 미완성 줄은 보너스 없음, 가로·세로·대각선 합산, 선택 변경 시 재굴림 없음, 채운 칸 금지,9번째 배치 후 추가 난수 소모 없음,300개 결정적 전체 경기.
- 공통 저장: 게임별 분리, JSON 복구, 완료 중복 방지,100건 보관 후 오래된 완료 세션 재삽입 방지, 손상 데이터 백업,저장 거부/용량부족,완료기록 저장 재시도.
- 실제 Chromium 브라우저 자동화: 홈3종 진입과 기존 숫자야구,코드 성공/실패,리버스 해결,주사위9턴,기록 조회,새로고침,다른 탭 진행 반영,새 도전 취소,손상/차단 저장소.
- 화면:1280px 데스크톱,390px·320px 모바일 폭 가로 넘침 점검.390px3종과 홈·데스크톱 주사위 화면을 캡처·검토. 모바일 주사위 선택부를 보드 위로 이동해 스크롤 중 유지.
- 기존 전체 테스트: 트리플 코드·기억의 짝·숫자야구·불빛 뒤집기·미니 체스·온라인 방/HTTP/CORS 동기화 통과. 이전 로컬 덱 엔진 테스트도 유지되지만 새 화면에는 연결하지 않음.

## 확인된 문제와 조치

- 기존 검증기는 `?game=`가 있는 로컬 링크를 파일명 전체로 인식했다. 경로 확인 시 쿼리와 해시를 제거하도록 수정했다.
- 모바일 공통 스타일이 첫 내비게이션 링크를 숨기므로 신규 탭에는 명시적으로 표시하도록 보완했다.
- 기록100건 이후 예전 완료 세션을 다시 불러오면 과거 기록이 새 기록처럼 삽입될 수 있었다. 게임별 완료 마커로 방지했다.
- 브라우저 테스트의 첫 실행은 잘못된 게스트 ID 형식으로 안내창이 열려 실패했다. 테스트 데이터를 기존 `guest_` 형식으로 고쳐 재실행했고 통과했다. 제품의 게스트 규칙은 변경하지 않았다.

## 실행·검토

`node verify.cjs`로 전체 로직·자산 검증. `foundation-browser-tests.cjs`는 기존 설치 Playwright와 Chromium을 환경변수로 지정해 실행하며 새 소프트웨어를 설치하지 않는다. 브라우저 캡처와 결과 JSON은 채팅의 로컬 시각화 폴더에 보관한다.

로컬 미리보기: `http://127.0.0.1:4189/index.html` 및 `solo.html?game=code`, `solo.html?game=reverse`, `solo.html?game=dice`. 미리보기 서버가 종료되면 `python -m http.server 4189 --bind 127.0.0.1 --directory dist`로 다시 열 수 있다.

## 한계와 다음 단계

사이트 배포·GitHub push는 하지 않았다. 실제 휴대전화, 다른 브라우저, 스크린리더,게임 재미·소요시간·별 난이도는 미검증이다. 두 탭의 순차 진행 반영은 확인했으나 완전히 동시에 발생하는 기록 쓰기의 충돌 해결·서버 동기화는 구현하지 않았다. 현재 기록은 브라우저 로컬 데이터이며 공용 랭킹용 인증 점수가 아니다. 다음은 로컬 결과 사용자 검토 후 배포 범위 결정이다.
