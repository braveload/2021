# Picture practice architecture

`learning-core.js` contains deterministic lesson fixtures and feedback helpers. `lights-practice.js`, `triple-practice.js`, and `code-chain-practice.js` render separate native dialogs. Code and chain practice read only public `SoloCore.clues` semantics and card definitions; their local lesson variables never enter `SoloStore`, the real game session, or completion records. Closing or reloading discards practice progress. Existing game engines, rule versions, scoring, and persistence formats remain unchanged.

Homepage practice links use `?practice=1`; game pages also expose an explicit practice button. Schema descriptions are generated by `scripts/structured-data.cjs` from factual page capabilities, with no synthetic ratings/reviews. Pure lesson tests run in `verify.cjs`; live UI, preservation, and external validation evidence is logged in `implementation-log.md`.

Board practice: board-practice.js renders independent dice/line dialogs. Fixed fixtures in LearningCore use SoloCore.diceScore/lineScore and previewDice directly. No main-game actions or storage writes; line examples explicitly omit AI turns and use simplified example boards. SVG connections track rendered cell centers through ResizeObserver. Practice completion never submits a game record.
