# 미니 체스 온라인 친구 대전 베타

- 닉네임 게스트 → 방 생성/6자리 코드 입장 → 양쪽 준비 → 서버 판정 대전 → 재대결.
- 각 기기/탭은 서버에서 발급받은 256비트 게스트 토큰을 sessionStorage에 보관합니다. 토큰을 초대 링크에 넣지 않습니다.
- REST 상태 조회(1.5초 간격), 서버 이동 검증, 참가자 인증, 버전 충돌 검사, 중복 요청 차단.
- 기존 게임 규칙 v0.1 유지. 온라인에서도 턴 시간 제한은 없습니다.
- 경기 중 15초간 연락이 없으면 연결 끊김으로 표시합니다. 경기당 1회 60초 복귀 유예 후 기권, 두 번째 연결 끊김은 기권입니다. 복구 중에는 양측 이동을 막습니다.
- 방은 마지막 활동 후 30분 동안 임시 보관하며 서버 재시작/배포 시 초기화됩니다. 최근 10경기 결과는 방 내 임시 보관입니다.
- 무료 Render 단일 인스턴스 메모리 서버입니다. 휴면 해제 첫 연결은 오래 걸릴 수 있습니다. 영구 계정/DB/랭킹은 없습니다.

## 실행
`node server/server.cjs` (PORT 기본 10000, 0.0.0.0 수신)
검증: `node verify.cjs`

## 배포
기존 Static Site의 빌드: `node '판루딕/build-render.cjs'`, 공개 경로: panludiq-public.
추가 Web Service: node, free, singapore, 빌드 `node '판루딕/verify.cjs'`, 시작 `node '판루딕/server/server.cjs'`.
`dist/online-config.js`에 실제 추가 서버 주소를 설정합니다.
