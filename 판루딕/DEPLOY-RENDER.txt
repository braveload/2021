판루딕 Render 게스트 베타 배포 패키지 v0.3.0
2026-10-31

포함 내용
- 첫 방문 시 게스트 입장: 닉네임 선택 입력, 빈칸이면 자동 생성
- 게스트 정보는 localStorage에 저장, 홈과 미니 체스 간 유지
- 서버 계정 인증이 아닌 브라우저 내 게스트 프로필
- 트리플 코드 / 기억의 짝 / 나인 블러프 싱글 3종
- 12칸 미니 체스 로컬 2인 플레이
- 기본 3종 기록은 브라우저 공용 기록이며 닉네임 변경 시 분리되지 않음
- 미니 체스 경기는 새로고침 시 초기화, 영구 기록 및 계정 동기화 없음
- 온라인 대전, 초대방, AI 미니 체스, 공용 랭킹은 미구현
- 기존 게스트 저장이 제한되면 현재 페이지에서만 사용 가능

Render 설정
1. 이 폴더의 내용을 braveload/2021 저장소의 판루딕/ 하위에 업로드합니다.
2. Render > New > Static Site에서 해당 저장소를 연결합니다.
3. 아래 값을 설정합니다.
   Name: panludiq (사용 가능 여부에 따라 변경)
   Branch: 실제 코드를 올린 브랜치 (예: main)
   Root Directory: 비워두기 (저장소 루트 기준 명령 사용)
   Build Command: node '판루딕/verify.cjs'
   Publish Directory: 판루딕/dist
4. Create Static Site를 실행합니다.
5. 배포 성공 후 발급된 URL에서 첫 게스트 입장, 닉네임 유지, 3종 게임 시작 및 미니 체스 진입을 확인합니다.

이 패키지는 순수 HTML/CSS/JS이므로 Web Service나 데이터베이스가 필요하지 않습니다.
서버용 Start Command도 필요하지 않습니다. Static Site로 생성해야 합니다.
별도 환경변수 및 API 키가 필요하지 않습니다.
현재 서비스에 덮어쓰기 전 해당 서비스가 판루딕 전용인지 확인합니다.
외부 배포 권리/등급/정책 검토는 별도이며 공개 운영 가능 여부를 보증하지 않습니다.

로컬 확인
- dist/index.html을 브라우저로 열기
- 또는 패키지 루트에서 npm start 후 http://localhost:8000 에 접속(Python3 필요)
- 검증: npm run build

현재 실제 배포 상태
- 로컬 코드 및 배포용 패키지 준비 완료
- Render 워크스페이스: 티거's workspace
- 대상 Git 저장소: braveload/2021, 하위 폴더: 판루딕
- 실제 배포 상태는 Render 대시보드에서 확인
